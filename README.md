# E-Commerce QA Testing Project

## 📌 Project Overview

This project demonstrates practical QA testing skills for an E-Commerce application using Manual Testing, Jira, Postman API Testing, and SQL Database Testing.

The project covers functional testing, negative testing, regression testing, API validation, defect reporting, and database validation.

## 🛠️ Tools & Technologies

- Manual Testing
- Jira
- Postman
- API Testing
- SQL / MySQL
- Git & GitHub
- Regression Testing
